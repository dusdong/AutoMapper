# Du.AutoMapper

此包提供 AutoMapper 14 的维护版本，保留 `AutoMapper` 程序集和命名空间。

```sh
dotnet add package Du.AutoMapper --version 14.0.0
```

```powershell
Install-Package Du.AutoMapper -Version 14.0.0
```

包版本见 [Du.AutoMapper](https://www.nuget.org/packages/Du.AutoMapper/)。维护问题请提交到 [维护仓库](https://github.com/dusdong/AutoMapper/issues)。
