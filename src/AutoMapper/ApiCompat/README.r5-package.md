# Du.AutoMapper 14.0.1 本地候选

此包提供 AutoMapper 14 的集合映射上下文补丁，保留 `AutoMapper` 程序集和命名空间。安装前，为项目配置包含本轮候选主包的本地 NuGet 包源，并保留 nuget.org 用于还原第三方依赖。

```sh
dotnet add package Du.AutoMapper --version 14.0.1
```

```powershell
Install-Package Du.AutoMapper -Version 14.0.1
```

维护问题请提交到 [维护仓库](https://github.com/dusdong/AutoMapper/issues)。
