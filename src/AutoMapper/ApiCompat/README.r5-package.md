# Du.AutoMapper 14.0.1

此包提供 AutoMapper 14 的集合映射上下文补丁，保留 `AutoMapper` 程序集和命名空间。可从 nuget.org 安装维护版。[Du.AutoMapper 14.0.1 包页面](https://www.nuget.org/packages/Du.AutoMapper/14.0.1)

```sh
dotnet add package Du.AutoMapper --version 14.0.1 --source https://api.nuget.org/v3/index.json
```

```powershell
Install-Package Du.AutoMapper -Version 14.0.1 -Source https://api.nuget.org/v3/index.json
```

维护问题请提交到 [维护仓库](https://github.com/dusdong/AutoMapper/issues)。
